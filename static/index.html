About This Model

CreditGuard AI is powered by a machine learning model trained on real-world lending data. It predicts whether a loan applicant is likely to default based on 11 carefully selected features — spanning personal demographics, loan characteristics, and credit bureau history.

The model uses an optimized probability threshold (stored in best_threshold.pkl) to balance precision and recall, making it suitable for real-world lending decisions.
